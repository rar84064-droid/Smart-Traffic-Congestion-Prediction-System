# Smart-Traffic-Congestion-Prediction-System
This project presents an intelligent machine learning-based system for predicting traffic congestion levels (low, medium, high) using weather data and time-related factors. The model was trained using the Metro Interstate Traffic Volume dataset, which contains approximately 48,000 records. Several algorithms were evaluated, including Logistic Regression, KNN, Neural Networks, and Random Forest. The results showed that the Random Forest model achieved the highest accuracy of 93%, making it the most efficient. This system contributes to improving traffic management and supporting decision-making by providing accurate predictions.
